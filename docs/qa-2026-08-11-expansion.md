# 診斷擴充與症狀導引 QA（2026-08-11）

## 這一輪改了什麼

1. 診斷庫從 12 個擴為 **61 個**（7 個部位），分型 26 → 125，動作 34 → 121。
2. 新增**症狀導引**：部位 → 紅旗篩檢 → 病史問答 → 理學檢查 → 診斷或轉介，共 50 個步驟。
3. 每個診斷新增**衛教說明**（這是什麼／為什麼／病程／常見誤解）、**活動調整與生活建議**、**回診與轉介時機**，
   同時出現在病人端與紙本。
4. 病人端改為**靜態處方頁**：移除進度追蹤、完成標記、「前往下一個」按鈕、展開收合與計時器，所有內容一次展開。
5. 網址短碼改為 v2（由資料檔的 `code` 欄位產生）；v1 與更早的 base64 對照表凍結保留。
6. 新增開發模式資料檢查 `src/lib/validate.ts`。

## 通過項目

- `npm run build`（tsc 型別檢查 + vite 建置）成功。
- 開發模式資料檢查：**通過，0 個問題**。過程中實際攔到 11 個錯誤並修正：
  - 9 筆分型指向了未標記該部位的動作（例如 GTPS 的踝幫浦、ITBS 的臀肌等長）。
  - 2 個診斷（髖／膝置換術後）當時只能手動選取，無法從症狀導引到達。
- 症狀導引三條完整路徑實測：
  - 胸腰背 → 腿部症狀過膝 → 咳嗽加重 → SLR 陽性 → **腰椎神經根病變**。
  - 足踝 → 腳跟後方 → 壓痛在跟骨上方 2–6 公分 → **跟腱中段疼痛**。
  - 肘腕手 → 麻木為主 → 前三指半夜間麻醒 → 正中神經測試陽性 → **腕隧道症候群**。
- 紅旗勾選任一項會即時顯示轉介建議並收起「繼續」按鈕；取消勾選可繼續。
- 「上一步」可退回並清除該步之後的軌跡；退回紅旗步驟會同時取消已通過的安全篩檢狀態。
- 導引通過紅旗後自動帶入安全篩檢的「可開立」，並顯示來源說明；醫師仍可改為轉介。
  實測：膝 → ITBS 採用後 QR 可產生；連按三次「上一步」退回紅旗步驟，安全篩檢立即失效、QR 重新鎖定並提示
  「請先完成安全篩檢」。
- 診斷庫路徑（未經導引）仍強制安全篩檢：直接點選膝關節退化時 QR 鎖定，完成篩檢後才解鎖。
- 紙本列印版含動作三步驟、提醒、認識您的問題、活動調整與生活建議、回診與轉介時機，以及原有的停止與就醫警語。
- 適用邊界鎖：跟腱中段未勾選確認時 QR 維持鎖定，提示「請先確認這個診斷的適用邊界」。
  同一機制已套用到跟腱附著點、旋轉肌撕裂保守期、壓迫性骨折、髖／膝置換術後、ACL。
- 腰痛走路快篩仍會停用伸展方向；`avoidFor` 機制讓俯臥撐起與站姿後伸在狹窄、滑脫、壓迫性骨折時不出現在選單。
- v2 連結可解碼並正確渲染：`2.f4.f41.f08-r-10-2-w3~f09-r-5-2-d1~f10-r-8-2-w3.260811`（62 字元，QR 比舊版更短）。
- 舊版 v1 連結仍可解碼：`1.s.sh.p-r-10-2-d2~ts-r-8-2-d2~ce-r-8-2-d2.260810` → 五十肩・高敏感期，三張圖片正常載入。
- 病人端確認無計時器、無 sticky 按鈕、無進度條。
- 無圖動作（枕下肌放鬆、上斜方肌伸展）不顯示圖片區塊，只放大步驟文字；有圖動作正常顯示。
- 390×844 手機視窗：醫師端起始頁、紅旗頁、導引完成後，以及病人端，`scrollWidth` 均等於 `clientWidth`，無水平溢出。

## 已知限制

- 新增的 49 個診斷多數沒有專屬 CPG，內容由同類原則延伸，證據等級較低（見 `clinical-evidence.md` 的分級）。
- 本輪新增的三筆指引引用只寫名稱、未驗證網址（標為「連結待補」）。
