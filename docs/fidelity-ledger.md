# 視覺 fidelity ledger

最終 QA：2026-08-10。以 Codex in-app browser 在原生 1440×1000（醫師端）與 390×844（病人端）視窗驗證，並將實作截圖和 ImageGen 概念稿並排檢視。

| 比較點 | 概念稿 | 最終實作 | 結果 |
| --- | --- | --- | --- |
| 整體構圖 | 醫師表單約 60%，右側手機預覽約 40% | 保留雙欄與固定手機預覽；窄螢幕改為上下排列 | 忠實 |
| 視覺語言 | 白底、深海軍藍、尤加利綠、淺藍資訊、杏色警示 | 使用同一組語意色彩、細框線、大留白、低陰影 | 忠實 |
| 開立流程 | 診斷 → 分型 → 核心動作 → QR | 增加強制安全篩檢，核心動作改為第 4 步 | 有意調整（安全） |
| 動作數量 | 固定 3 個動作 | 預設 3 個，但醫師可刪到 1 個、上限 3 個 | 有意調整（個人化） |
| 病人畫面 | 診斷頁首、3 列動作、展開步驟、60 秒計時、底部行動鈕 | 保留全部核心元素，另加開立日期與完成進度 | 忠實並增補 |
| 運動圖像 | 單色線稿動作示意 | 以統一醫療線稿風格的原創圖像落地至每個動作 | 忠實 |
| 安全提醒 | 簡短停止規則 | 區分「先停止」與「立即就醫」，醫師端警訊會直接阻擋 QR | 有意強化 |
| QR 與隱私 | 手機預覽下方 QR、不含個資 | 使用版本化短編碼與網址片段、無後端與個資，另提供離線快取與紙本列印 | 忠實並提升現場可靠度 |
