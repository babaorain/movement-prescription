# PE／DD 證據說明與來源核對

更新日：2026-08-28

用途：成人、非術後、非重大急性外傷、非原發神經疾病主導的門診／義診肌骨評估。

## 判讀原則

- 網站顯示的是特定研究族群、操作方式與參考標準下的 sensitivity（Sn）與 specificity（Sp），不是所有病人的固定常數。
- 能由系統性回顧或可識別的診斷研究抽取時才顯示數字；沒有穩定估計時明示「無穩定估計」，不以經驗值補空白。
- DD 排序是結果整理工具，不是機率模型。陽性結果依 Sp 給予較多 rule-in 支持，陰性結果依 Sn 降低支持；沒有可靠點估計的測試只給很小權重。
- 單一測試不可獨立確診。測試需與病史、pre-test probability、基礎神經學、相鄰部位來源與必要影像／檢驗一起解讀。
- 診斷準確度不是處方有效性證據；PE 模組與運動處方模組分開呈現。

## 搜尋與核對方式

以 PubMed／PMC 的原始條目核對題名、年份、族群與摘要數值；優先採用系統性回顧與統合分析，其次採診斷準確度研究。搜尋概念包括各區域疾病名稱、physical examination、diagnostic accuracy、sensitivity、specificity、systematic review。數字若只來自單一、小型或專科轉介研究，卡片會標為低確定性並寫出外部效度限制。

本次為快速臨床工具的 evidence verification，不是完整 PRISMA 系統性回顧；沒有執行雙人篩選、完整 risk-of-bias 表或 GRADE 證據摘要。利益衝突與全文細節未能由所有摘要一致取得，正式臨床規範仍應回到全文與在地 guideline。

## 為何部分檢查沒有 Sn／Sp 數字

基礎 AROM／PROM、觸診、神經分布、功能負荷與許多常見特殊測試，常面臨以下任一問題：沒有可信的 reference standard、不同研究把「疼痛」「無力」「不穩」混成同一陽性定義、操作版本不同、樣本太小，或研究族群只限運動員／手術轉介者。網站仍保留它們，因為它們能協助定位、比較、確認負荷反應或形成 cluster；但卡片會明示無穩定估計，DD 演算法也只給極小權重。

## 維護規則

1. 新增數字前必須能指出可開啟的 PubMed／PMC 或正式 guideline 來源。
2. 優先更新 pooled estimate；若只有 range 或最佳單篇研究，就照原樣標示，不轉成虛假的單一點估計。
3. 任何數字更新都要同步修改 `src/data/physical-exams.ts`、本文件與資料檢查。
4. 義診現場若遇到範圍外個案，應離開本流程，不用「最接近的 PE」硬套。
