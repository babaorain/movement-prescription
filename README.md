# 動作處方

復健科義診使用的個人化居家運動處方工具。醫師可快速選擇診斷、臨床分類、1–3 個核心動作與劑量，再產生不含個資的 QR code 給病人使用。

## 目前範圍

- 五十肩：依疼痛敏感度提供高／中／低敏感期組合
- 非特異性下背痛：先做走路症狀快篩，再選一般活動或經重複動作確認的方向偏好
- 病人手機版：圖像步驟、60 秒引導計時、完成進度與白話安全提醒
- 首次成功載入後可離線再次開啟，另有紙本列印備援

## 本機開發

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## 隱私與臨床邊界

處方資料直接編碼於網址片段（`#rx=`）中，不含姓名、病歷號或其他個人資料，也不儲存於後端。網址片段不會隨一般 HTTP 請求送到伺服器；頁面另設定 `no-referrer`，且不載入第三方分析程式。本工具協助醫師傳遞運動建議，不提供診斷，也不取代臨床評估與轉介判斷。
